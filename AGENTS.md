This is a repo to prepare Alaric runs in a web interface. The server-side backend is Seamless. You can examine Seamless documentation in ~/seamless1/seamless/docs .
- Tests are to be run in the `preparic` conda env. 
- The `preparic` conda env contains a `pip -e` install of the Seamless repos.
- Activate Serena and use it for this project. Activate the current dir as project using serena.
You can use Serena separately for the Seamless repos, if needed.

For source-code exploration, prefer Serena symbol/overview/reference tools.
Do not read an entire source file when a symbol, pattern, or bounded line
range is sufficient. Before rereading an unchanged file, determine whether
the required symbol/range has already been inspected.
